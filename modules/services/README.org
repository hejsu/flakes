#+title: 服务放置规则

* 服务放置规则
- =modules/= 下每个文件都会被自动收集导入：跨平台模块须兼容 Darwin，Linux 专属模块在 =modules/_darwin/default.nix= 的 =disabledModules= 中排除，按需启用的能力提供 =enable= 开关。
- =modules/services/=：跨主机的常驻守护进程（openssh、sing-box、caddy）。
- =profiles/=：被选择才生效，可以直接写原生 option，不需要 enable。
- =hosts/<host>/=：单机配置，扁平，经 includes 引入，不写 enable、不建子目录。
- 暴露方式（=services.tailscale.serve= / =services.caddy.virtualHosts=）属于应用，
  放在 host 文件里；TLS/ACME 策略属于 Caddy 能力，放在 =modules/services/caddy.nix=。
