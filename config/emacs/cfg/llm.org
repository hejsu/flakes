* Secrets

API keys live in `authinfo' inside this directory rather than in `~'.
`gptel-api-key' defaults to `gptel-api-key-from-auth-source', which looks
up `:host <backend host>' and `:user "apikey"' here.

#+begin_src emacs-lisp
  (setq auth-sources (list (expand-file-name "authinfo" user-emacs-directory)))
#+end_src
